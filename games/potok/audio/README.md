# Треки для игры «Поток»

Сюда положи аудио-файлы (`.mp3`, `.ogg`, `.wav`) и пропиши их имена в `index.json`:

```json
{ "tracks": ["track1.mp3", "track2.mp3"] }
```

Игра сама выберет один из треков случайно при старте и раунде «🔀 Трек». Если список пустой или файлы не подгружаются — автоматически играется синтетический сигнал.

## Пример скачивания с YouTube

```
yt-dlp -x --audio-format mp3 --no-playlist \
  -o "track1.%(ext)s" \
  "https://m.youtube.com/watch?v=K3E6Y13xLZM"
```

Требуется установленный `yt-dlp` и `ffmpeg`. Если возникают SSL-ошибки в контейнерном/sandbox-окружении — выполняй загрузку локально и клади готовый файл в эту папку.
